TÊN ĐỀ TÀI: WEBSITE BÁN ĐỒ THỂ THAO

GIỚI THIỆU WEBSITE HỆ THỐNG
Hệ thống WEBSITE BÁN ĐỒ THỂ THAO là một website thương mại điện tử chuyên cung cấp các mặt hàng, thiết bị và trang phục thể thao được xây dựng dựa trên ngôn ngữ PHP thuần và cơ sở dữ liệu MySQL. Dự án mang lại trải nghiệm mua sắm trực tuyến trực quan cho khách hàng với các chức năng xem danh mục, giỏ hàng, đặt hàng và tích hợp thanh toán trực tuyến, đồng thời cung cấp giao diện riêng biệt hỗ trợ quản lý sản phẩm và đơn hàng cho Admin.

HƯỚNG DẪN CÀI ĐẶT

Tải mã nguồn bằng cách clone repository từ GitHub về máy local qua lệnh: git clone https://github.com/DoHoangNam-23810310303/webbh1_dohoangnam_nguyenhongphong.git

Di chuyển thư mục dự án vừa tải về vào trong thư mục root của phần mềm quản lý server cục bộ (thư mục htdocs đối với XAMPP).

Khởi động phần mềm XAMPP lên, sau đó nhấn Start hai dịch vụ Apache và MySQL.

Mở trình duyệt web, truy cập vào đường dẫn http://localhost/phpmyadmin để vào trang quản lý cơ sở dữ liệu.

Tạo một cơ sở dữ liệu mới với tên gọi tùy chọn .

Nhấp chọn vào cơ sở dữ liệu vừa tạo, tìm và ấn vào tab Import (Nhập), sau đó chọn file dữ liệu có đuôi .sql nằm trong thư mục mã nguồn của dự án để nạp toàn bộ cấu hình bảng và dữ liệu mẫu vào hệ thống.

Mở mã nguồn dự án bằng công cụ lập trình, tìm đến file cấu hình kết nối database (config.php) và sửa lại các thông số kết nối bao gồm tên host, tên đăng nhập, mật khẩu và tên cơ sở dữ liệu cho khớp với cấu hình máy cục bộ của bạn.

HƯỚNG DẪN CHẠY PROJECT

Hãy đảm bảo dịch vụ Web Server Apache và Database Server MySQL trên ứng dụng XAMPP hoặc Laragon đang được bật và chạy ổn định.

Mở trình duyệt web bất kỳ trên máy tính của bạn.

Truy cập vào giao diện của khách hàng dành cho người mua sắm theo đường dẫn: http://localhost/WEBBH1/WEBBH1/WEBBH1/index.php

Truy cập vào giao diện quản trị điều hành của hệ thống theo đường dẫn: http://localhost/WEBBH1/WEBBH1/WEBBH1/admincp/index.php
